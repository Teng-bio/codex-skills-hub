# Trigger keywords for Project Flow Guard

Use this reference when tuning task classification.

## Run / artifact generation

Chinese:

- 重跑, 重新跑, 重新生成, 重新导出, 重新计算, 重新统计, 重新分析
- 重新绘图, 重新画图, 再生成一版, 换一版, 改一版, 出一版

English:

- rerun, regenerate, replot, rebuild, recompute, export again, new version

## Child run / variation

Chinese:

- 改一下, 调整一下, 微调, 换颜色, 换字体, 改标签, 改图例, 改标题
- 调整布局, 换参数, 阈值改成, 参考换成, 基于这版, 在这个基础上

English:

- based on this, change parameter, change style, try another, revise this version

## Promote

Chinese:

- 保留这个版本, 保留这版, 这个可以, 就用这个
- 这个作为当前版本, 设为当前版本, 作为最终版本

English:

- make current, keep this version, accept this, promote this, use this version

## Baseline

Chinese:

- 冻结当前版本, 锁定当前版本, 保存当前状态, 做一个快照
- 当前作为 baseline, 当前作为起点, 封版

English:

- snapshot, baseline, seal, freeze current state, save baseline

## Branch

Chinese:

- 开一个分支, 新建分支, 大的分支, 新的分析方向
- 基于这个版本继续, 同样的数据做另一个分析, 另起一条线

English:

- branch, branch from current, fork this analysis, same data new analysis, new analysis direction

## Checkpoint and branch

Composite intent when promote/baseline/branch are combined:

- 保留这个版本并继续
- 基于这个版本开分支
- 这个版本作为起点
- 保存当前状态然后做另一套分析
- freeze this and branch
- checkpoint and branch

## Release

- 准备投稿, 发表数据, 整理发表版本, 打包, 发布版本, 最终交付
- release, package, publication release, submission package

## Cleanup

- 清理, 整理目录, 删除旧版本, 删掉中间文件, 归档旧版本, 压缩旧结果
- cleanup, reorganize, delete old versions, archive old runs
