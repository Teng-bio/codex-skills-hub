# Section Workflows

## Title

Aim for `system + approach/finding + biological implication`. Avoid titles that imply causality if the evidence is association-only.

## Abstract

Use:

`context -> gap -> approach/data -> key finding -> validation/support -> implication -> boundary`

Include quantitative details only if supplied. Keep methods and results connected so the reader can see how evidence supports the main claim.

## Introduction

Use:

`field importance -> known biology -> unresolved computational/biological gap -> why prior work is insufficient -> present study`

Do not preload all Results. End with what the study tests or builds.

## Results

Use a claim-first sequence:

`analysis setup -> primary observation -> statistical support -> secondary/validation evidence -> limited interpretation`

Do not discuss broad implications inside Results. Route detailed figure-by-figure work to `bio-results-writing`.

## Discussion

Use:

`central finding -> meaning in prior context -> evidence strength -> biological or methodological implication -> limitations -> next step`

Separate direct conclusions from hypotheses. Mention missing external validation, batch effects, small sample size, retrospective design, or database-only support when relevant.

## Conclusion or significance paragraph

Use:

`what was shown -> why it matters -> where it applies -> what remains uncertain`

No new results or unsupported promises.
