# Query Patterns

Use these patterns when expanding a user request:

- Academic: `<topic> review recent advances site:arxiv.org OR site:pubmed.ncbi.nlm.nih.gov OR site:nature.com OR site:science.org`
- Software: `<tool/framework> official docs changelog benchmark comparison 2026`
- Project skill search: `<domain/task> Codex skill Claude Code skill SKILL.md GitHub`
- Verification: exact claim in quotes + primary source domain if known.

Prefer 3-6 targeted queries over one vague query.
