## PROJECT_STATE Policy

- Before substantive work, read `PROJECT_STATE.md` in the project root.
- Treat `PROJECT_STATE.md` as the canonical project handoff and current status file.
- Before finishing any turn that changes project understanding, decisions, or files, update `PROJECT_STATE.md`.
- Keep `Current Status`, `Recent Changes`, `Open Problems`, `Next Step`, and `Resume Prompt` current.
