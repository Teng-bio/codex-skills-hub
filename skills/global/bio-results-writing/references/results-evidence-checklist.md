# Results Evidence Checklist

Use this checklist before drafting or revising Results prose.

## Figure/table card

For each evidence item, collect:

- item ID and panel labels
- assay or analysis type
- dataset, organism, tissue/cell type, and sample groups
- comparison or contrast
- statistic fields: effect size, confidence interval if any, p value, FDR, threshold, number of genes/features/samples
- validation status: internal, external, orthogonal, or none
- figure status: final, draft, placeholder, supplementary, or missing
- safe message: one sentence that the item directly supports

## Common omissions to flag

- Missing group definitions or sample counts
- Missing multiple-testing correction
- Unclear background set for enrichment
- Gene ID namespace not stated
- Batch/covariate not addressed
- Figure message stronger than statistical support
- Main text refers to a panel not supplied
- Results paragraph explains mechanism without supporting experiment or external validation

## Safe wording examples

- Direct observation: `We observed...`, `The analysis identified...`
- Association: `was associated with`, `correlated with`, `was enriched among...`
- Exploratory result: `suggesting a possible`, `consistent with`, `raising the possibility that...`
- Missing validation: `These findings require validation in independent datasets or experimental systems.`
