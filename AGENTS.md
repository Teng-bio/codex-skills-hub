# AGENTS.md — codex-skills-hub

This repository stores and manages local Codex/agent skills.

## Rules

- Prefer dry-run before changing mirrored skill content.
- Do not commit secrets, tokens, private keys, `.env`, or cache directories.
- Do not treat mirrored external skills as authored local skills.
- New authored skills go under `skills/local/<skill-name>/`.
- Keep `registry/SKILL_INVENTORY.tsv` and `registry/skills.json` generated by `scripts/sync_skills.py`.
- Validate before commit:
  - `python scripts/validate_skills.py`
  - `python scripts/sync_skills.py --dry-run`

## Skill creation checklist

1. `SKILL.md` has YAML frontmatter with `name` and `description`.
2. Description contains clear trigger conditions.
3. Body is concise and uses progressive disclosure.
4. Scripts/assets/references are included only when useful.
5. No project-specific fake defaults are hard-coded into reusable skills.
